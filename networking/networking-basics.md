# Networking Basics (Day 1)

## IP Addresses
- 192.168.1.217 → local network IP
- 127.0.0.1 → localhost (loopback)

## Networks I saw on my system
- lo → loopback interface
- wlp2s0 → WiFi interface
- docker0 → Docker bridge network (172.17.0.1)

## Key idea
A computer can have multiple networks at the same time.

## Docker concept
docker0 behaves like a virtual private network for containers.
